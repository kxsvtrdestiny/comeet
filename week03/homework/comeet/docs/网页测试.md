# 第一阶段 GitHub Pages 测试站

2026-11-09，用户明确授权推送后，源码分支 stage1-review 与静态分支 gh-pages 均已推送，并用 git ls-remote 确认远端存在。此记录不代表已验证 GitHub Pages 公网发布。

## 开启 Pages（仓库尚未开启时）

1. 在自己的浏览器登录 GitHub，打开 https://github.com/kxsvtrdestiny/comeet/settings/pages 。
2. Build and deployment → Source 选择 **Deploy from a branch**。
3. Branch 选择 **gh-pages**，目录 **/(root)**，点击 **Save**。
4. 等待 GitHub 的 pages build and deployment 完成；以页面显示的 Visit site 地址为准。

预期网址：https://kxsvtrdestiny.github.io/comeet/#/ 。该地址需要 Pages 实际完成发布后才能访问，不能用云端 localhost 替代。

已知入口：`#/login`、`#/register`、`#/meetings/preview/prepare`、`#/meetings/preview/room`、`#/history`。页面全部是第一阶段骨架，账号/会议操作禁用。

源码 ZIP 可直接从 GitHub 下载：https://github.com/kxsvtrdestiny/comeet/archive/refs/heads/stage1-review.zip 。也可在静态站首页点下载源码。解压后按 README 的 Windows 两终端步骤启动完整前后端。

## 验证范围

静态服务器本地检查了 7 路由 × 4 宽度，共 28 项，加载/刷新与无横向溢出通过；确认 Pages 模式不请求 /api、不显示假数据库成功，ZIP 能下载。普通构建及实际 Go health 错误重试回归通过。

GitHub 管理 API 与 github.io 域名被本云环境策略拒绝，无法自动确认 Pages 设置或从云端检查公网网址；公开仓库网页探测也未提供可用管理信息。需要用户完成上述必要设置并实际打开验证。没有请求个人 token，没有更改仓库可见性或进入第 2 阶段。

GitHub Pages 只支持静态前端，不运行 Go/SQLite。因此本站只用于界面方向验收，数据库与完整启动验收仍按 README 在 Windows 执行。
