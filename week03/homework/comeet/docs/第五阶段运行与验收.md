## 本次功能

- 屏幕共享通过用户直接点击触发 `getDisplayMedia`，发布真实 LiveKit ScreenShare 视频轨道。取消选择不报业务错误；页面停止、系统停止、采集/发布失败、迟到结果及离会均清理轨道。当前不采集系统声音，会议声音仍走原来的麦克风订阅，避免重复播放。
- 摄像头与共享分别使用 session identity + source，成员列表每人只有一行。主画面及缩略图可选择多个共享来源；共享 contain、不裁切、不镜像。自动模式优先共享，并稳定保留当前有效共享；手动固定不被新共享抢占。共享停止后自动回退；普通摄像头关闭仍保留占位。保留第四阶段浅色、可收栏、专注观看及聊天行为。
- 主持人从成员面板执行一次静音、移出；结束会议另有确认。Go 鉴权后核对会议创建者，不信任前端角色或 TrackSid。普通成员、跨会议目标、伪造字段、静音/移出自己均被拒绝。
- 一次静音：服务端查询目标媒体身份的麦克风轨道，使用官方 SDK `MutePublishedTrack(Muted=true)`；不改变发布权限，不提供远程开麦接口。未发布麦克风返回明确错误。成员收到“主持人已将你静音，你可以自行开麦”，可用原开麦按钮恢复。
- 移出：先持久化本场账号封禁并终止业务会话，join/resume/ws-ticket/media-token 均拒绝；再调用媒体移出。失败时返回非 2xx 并保留待重试操作，不能当作已完全清理成功。主持人刷新后仍可从会控结果/会议详情看到待重试操作。
- 结束：先持久化 ending、拒绝新加入/恢复/媒体授权，通知客户端退出并停止采集；撤销已知媒体身份、删除媒体房间成功后才写 ended。媒体失败保持 ending，主持人可在会议室或会议详情重试；启动时重试未完成的结束/移出操作。主持人个人离开仍不结束整场，可在会议详情结束。
- 操作 UUID 用于重试与完成去重；已成功的同一静音请求不会因 HTTP 响应丢失重放。移出/结束还按会议和目标合并。新增 004 迁移记录媒体授权身份/过期时间及会控操作，不存媒体 token；升级时保守记录旧版本仍可能有效的会话。不改 001–003，不清空旧数据。

## 外部服务边界与待验证项目

管理调用使用官方 Go SDK v2.19.0；RemoveParticipant 显式传 `RevokeTokenTs`（每次调用时的当前 Unix 秒 + 1，重试也刷新截止时间），不依赖默认时钟缓冲。已知媒体身份在删除房间前逐一移出；token 5 分钟、无管理授权，只有 camera/microphone/screen_share 发布源，不允许共享音频/data/远程改权限。

官方接口返回 NotFound 表示该目标/房间已不存在，按幂等清理处理。**Cloud 对旧 token 的实际撤销仍须真实服务验证**；自托管服务器可能不支持持久撤销或该字段，不能把短 TTL、空房间或只关闭业务 WS 宣称为严格媒体隔离。严格要求下请使用并验收 LiveKit Cloud。多媒体身份清理超过有界超时会保持 pending/ending，由原请求重试，不假报成功。

本云实例未注入 LiveKit 地址与密钥，因此真实 SFU 双向共享、物理屏幕选择/系统停止、真实远端静音后再开麦、Cloud 旧 token 重入及跨网络表现待验证。仿真采集/发布测试和本地管理 API 测试不替代这些项目。
