## 界面行为

- 会议笔记加入成员/聊天共用面板。桌面媒体区让出面板宽度，390px 则上下分区，不使用笔记遮罩。编辑区与保存按钮固定可找到，其他笔记/冲突信息内部滚动。
- 关闭/切换面板保留组件、未保存草稿和冲突内容；刷新恢复的是已保存内容，未保存内容仍有离页提醒。本人编辑权限、版本比较和原后端接口保留。只显示一个笔记标题。
- 移除媒体上方的选择提示行；只有手动固定时，右上方出现恢复自动选择。自动/手动优先级与选中标识不变。
- 会控反馈位于右下方浮动通知，桌面有面板时避让面板，窄屏避让笔记编辑/保存、聊天输入及底部工具栏。成功约5秒消失，失败可关闭/重试。通知有 status/alert 播报和键盘按钮。
- 移出和结束前仍需确认，收到后端完成结果才报成功。持久未完成操作可从成员面板或会议详情重试，刷新后从后端恢复，并非仅保存在通知中。
- 面板/通知没有加入媒体连接或采集依赖。真实 SFU 中是否无重复声音/采集，仍需双账号实测；普通浏览器回归只能证明此过程没有重复申请媒体凭证。

## 结束链路：证据与修复

代码确认旧实现每次遍历全部历史媒体身份，所有上游调用共享一个6秒截止时间，没有逐项持久完成记录。旧代码的定向回归复现：多个慢清理调用下，首次部分成功，重试仍重复前面的调用而不能推进。此为已经证实的代码缺陷，不能据此断言用户截图中的具体上游故障也是这个原因。当前云环境无真实 LiveKit 凭据和当时日志，不能确认那次究竟是鉴权、网络还是上游服务错误。

现在链路为：持久 ending/封禁 → 业务会话退出 → 快照媒体身份 → 分别清理身份 → 删除房间 → 最终落库完成。每步/身份都持久记录，手动、并发重复请求与启动恢复共用原操作和检查点。每次处理预算8秒，每个上游调用最多6秒；处理预算耗尽返回可重试提示，后续从未完成项继续。不会靠延长整批时间伪装问题解决。

身份快照包含上游实际在线身份、仍有效的已签发身份及本次退出的会话；过期且上游不存在的历史身份不再逐一重复处理。即使过期但仍在线，也会清理。移出只处理目标成员，结束还会删除整个房间。官方 SDK 明确返回 Twirp not_found 时，成员/房间清理视为已完成；普通网页404、鉴权与其他媒体错误不会忽略。

业务退出或媒体清理失败时，会议仍显示“结束中”，禁止重入；仅所有步骤和最终数据库事务成功才变成 ended。数据库写入失败不伪报成功。旧 pending 操作升级后会逐步建立检查点；不会篡改旧会议结束状态。

### 脱敏诊断与安全排障

页面错误包括失败步骤、可操作建议和诊断编号。后端 `media_control_failed` 日志含 request_id、operation_id、meeting_id、step、error_code；成功检查点记录 `media_cleanup_step_completed`，已不存在记录 `media_cleanup_absent`。不记录上游原文、URL凭据、Key、Secret、token、聊天内容。错误分类包括 TIMEOUT、UPSTREAM_AUTH、UPSTREAM_REQUEST、UPSTREAM_UNAVAILABLE、DNS_ERROR、NETWORK_ERROR、DATABASE_ERROR/DATABASE_TIMEOUT。

1. 不删除 data，不手改 ended，不盲目更换密钥。保留失败页面的诊断编号和步骤。
2. 后端 PowerShell 可将脱敏日志保存下来：

   ```powershell
   cd D:\comeet\server
   go run ./cmd/server -env-file .env 2>&1 | Tee-Object -FilePath .\data\server-diagnostic.log
   ```

3. 重试一次，按页面编号查找对应日志（将示例编号换成实际值）：

   ```powershell
   Select-String -Path D:\comeet\server\data\server-diagnostic.log -SimpleMatch '页面中的诊断编号'
   ```

4. TIMEOUT/NETWORK/DNS 检查运行 Go 的机器到 API 主机的网络；音视频连通不代表 Go 到管理 API 连通。UPSTREAM_AUTH 在本机核对 API 地址与 Key/Secret 来自同一项目，只报告是否一致，不发送这些值。UPSTREAM_REQUEST 检查是否错把页面/WS路径当管理API。DATABASE_ERROR 检查磁盘空间、权限、文件锁，保留库进行恢复。
5. 修正明确的问题后，主持人在详情/成员面板使用原待处理操作重试。重启也会恢复待处理操作，成功检查点不重放。若仍失败，只提供诊断编号、步骤和分类日志；不要上传 .env、token、数据库或完整聊天记录。
