## 修改内容与边界

- 真实会议室采用浅色，紧凑顶栏、固定可见工具栏，媒体区填充剩余视口。摄像头主画面 contain、缩略图 cover，本地仍镜像，视频画面本身不加滤镜。
- 默认聚焦、可切宫格；主画面与缩略条不重复挂载同一来源。点击缩略图、宫格“设为主画面”或成员行操作，选择自己/他人的画面。专注观看关闭侧栏和缩略条，退出按钮保留。
- 选择键使用 session identity + source，手动固定不因新人加入、说话或摄像头关闭而改变；关摄像头显示占位，短暂重连保留所选人，正式离会回退自动。布局切换保留选择，离开页面/换场清空。
- 仅预留来源模型的 camera/screenShare 类型和选择优先级；不生成共享源，不显示可用共享入口。
- 成员/聊天右栏默认关闭，可互相切换及再次点击关闭；聊天数据和草稿仍归原组件/RoomClient 管理，未读按实际新消息累计，补拉旧历史不增加未读。窄屏使用覆盖抽屉，支持关闭、Escape 和键盘焦点循环。
- 设备选择移动到工具栏“设备设置”对话框。正常连接信息收纳到“连接详情”；业务/媒体异常分别展示，只有业务确实已连接时才说“聊天仍可用”。设备错误、音频自动播放受阻和重试入口保留。
- 保留原有认证、数据库迁移、WS 协议、媒体授权、设备采集/发布、统一音频订阅、离会与清理逻辑。音频订阅组件不随画面切换重复挂载。

## Windows 更新和运行

安装 Node.js 24 和 Go 1.25.3。假设最终项目目录为 `D:\comeet`，其中直接包含 server、web 和 docs。

1. 停止旧前后端；备份原 `server\.env` 和整个 `server\data`。更新源码时保留这两个路径，不用源码模板覆盖 `.env`，不要删除数据库或更换已有 JWT_SECRET。最终只需 comeet 文件夹，不需要 week03/homework 外层。
2. 后端 PowerShell（保持开启）：

```powershell
cd D:\comeet\server
go version
go mod download
# 仅缺少 .env/本地 JWT 密钥时执行；会保留现有有效配置：
go run ./cmd/server -env-file .env -init-env
go run ./cmd/server -env-file .env
```

3. 前端另一个 PowerShell（保持开启）：

```powershell
cd D:\comeet\web
node --version
npm.cmd ci
npm.cmd run dev
```

安装依赖完成后再启动前端；重装依赖后重启 Vite，以免残留优化缓存。访问 `http://localhost:5173`，不要与 127.0.0.1 混用。后端内部默认 8080，前端代理 API/WS。

4. 沿用后端 `.env` 中自己的 `LIVEKIT_API_URL`、`LIVEKIT_WS_URL`、`LIVEKIT_API_KEY`、`LIVEKIT_API_SECRET`。如未配置，在后端本地填写并重启；不要把密钥放到 web/VITE_ 或聊天中。未配置时只能检查设备准备和真实文字会议，不能验证媒体传输。
5. Chrome 使用账号 A，Edge/独立隐私窗口使用账号 B；沿用已有账号或自行注册。A 创建会议，B 按同一个会议号加入，均授权麦克风/摄像头。戴耳机防止回声。
6. 停止服务：两个终端分别 Ctrl+C；下次只需重跑各自启动命令，不删除 `.env`/data。仅停止后端并在 45 秒内重启，可检查原有业务恢复规则。
