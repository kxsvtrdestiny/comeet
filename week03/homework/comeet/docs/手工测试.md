# 第 1 阶段人工验收（全部待用户执行）

按 README 在 Windows 两个 PowerShell 终端启动，不需要账号或任何媒体/模型密钥。使用桌面 Chrome 或 Edge，记录系统、浏览器版本及实际结果。以下项目由用户确认，Codex 不代为打勾。

1. 打开 http://localhost:5173：工作台侧栏、主操作和空态正常；创建/加入禁用并标第 2 阶段，没有假会议。
2. 查看“开发环境状态”：显示数据库初始化正常和 001_framework.sql，媒体/AI 未配置不阻止启动。也可直接访问 http://localhost:8080/api/v1/health/ready，预期 HTTP 200、database=ready。
3. 进入 /login 和 /register：布局简洁，标签与输入框清晰；输入测试密码，点眼睛能显示/隐藏；提交禁用，不创建真实账号。Tab 焦点可见。
4. 用首页底部链接打开准备页：设备选择/进入均禁用并标阶段，不出现摄像头权限弹窗；刷新页面不白屏。
5. 打开会议室骨架：深色主画面，无假视频/成员；成员/聊天标签可切换空态，媒体和共享按钮禁用；返回工作台有效。
6. 分别检查浏览器宽度约 1440、1024、768、390px：主要区域无明显横向溢出，按钮文字可读；登录、准备页、会议室刷新均正常。
7. 保持 Web 开启，Ctrl+C 停 Go，主页点“重新检查”：出现明确错误。按 README 重启 Go，再点检查恢复正常；数据库仍存在，终端不出现迁移重复错误。
