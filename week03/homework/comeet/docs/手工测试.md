## 8 项验收与预期

1. **配置与保护**：匿名打开 localhost:5173 应跳 /login；直接访问 http://localhost:8080/api/v1/health/ready 应见 stage=2、002_accounts_meetings.sql。没有 LiveKit/DeepSeek Key 仍能启动。
2. **注册与错误**：自行注册 A（如 student_a、显示名同学 A，密码自己选择），成功转登录。用 A 用户名的大小写变体重复注册应提示已使用；错误密码统一提示用户名或密码错误。
3. **A 创建**：A 登录，标题填“第二阶段测试”，创建后得到 9 位会议号并进入准备页。记录会议号和地址中的 UUID。进入按钮仍禁用并说明第 3 阶段接通；不申请设备权限。
4. **真实列表与刷新**：返回工作台应见该会议；刷新、搜索标题、筛选进行中，记录仍在；详情主持人为 A，会议号与准备页一致。
5. **独立 B 与权限**：用 Edge 或独立隐私环境访问 http://localhost:5173/register，注册/登录 B。输入 A 的会议号（可带连字符）能看准备页；直接访问 http://localhost:5173/meetings/实际UUID 应提示只有主持人或实际参会成员可查看详情。B 自己的列表不出现 A 的会议，因为尚未正式参会。错误格式/不存在会议号有明确提示。
6. **退出与返回地址**：B 退出后访问刚才准备页应跳登录，再登录 B 应返回原准备页。未到期但已撤销令牌、过期 JWT 拒绝和前端到期计时器由自动测试覆盖，无需人工等 8 小时；真实 8 小时等待没有测就记未验证。
7. **重启保留**：终端 A Ctrl+C，然后在 server 目录执行 `go run ./cmd/server -env-file .env`。保留 .env/data，不重新生成密钥。刷新 A 工作台，账号、会议和未过期登录会话应保留；确已到期则正常重新登录。health 恢复，无重复迁移错误。
8. **布局与范围**：1440/1024/768/390px 检查登录/工作台/准备页，无明显溢出和宣传标语。当前没有可用聊天/视频/共享。预留 API 的幂等、容量、并发、过期、唯一性已自动测试，UI 不假装正式入会。
